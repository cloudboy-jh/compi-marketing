See what’s running.

Read pane IDs and program-reported state. Capture another terminal’s output without taking over its view.

Make room for the next task.

Create a terminal, split the view or rearrange existing panes. Running processes stay where they belong.

Bring the result to you.

Open a file, a diff or a browser pane for review. No mouse-driving needed.

Use whichever agent can run shell commands. Compi supplies the controls, not an agent harness.

03Leave · keep running · return

Close the window.
Keep the work.

The window is a view into running work. Close it, reopen it and reconnect to the same shells.

01

Leave it running.

Your terminals live in Compi’s background server. Closing the window doesn’t end their processes.

02

Know when you’re needed.

Supporting programs report when they need attention or finish. Compi can notify you instead of making you check every tab.

03

Return to the terminal.

Click a notification to focus its terminal, or reopen Compi and pick up the same running work.

Restarting the server or rebooting ends running processes. Window persistence is not reboot survival.
