# Compi website

Static HTML, CSS and JavaScript for Compi. No application framework or runtime dependencies.

## Build and check

```sh
npm ci
npm run build
npm run check
```

The build generates `docs.html`, validates local references on both pages and copies 15 allowlisted public files into `dist/`. Markdown rendering uses a pinned build-time dependency; the deployed site has no runtime package dependencies.

## Preview

After building, serve `dist/` with any static HTTP server, for example:

```sh
python -m http.server 8791 --bind 127.0.0.1 --directory dist
```

Open `http://127.0.0.1:8791` in a browser. Use `python3` instead of `python` where appropriate.

## Deploy to Cloudflare Pages

Requires Node.js and an authenticated Wrangler CLI with Pages access.

```sh
npm ci
npm run build
npm run check
wrangler pages deploy dist --project-name compi-marketing --branch main
```

Only `dist/` is deployed. The build checks local asset references and copies an explicit public-file allowlist, excluding design drafts, local skills and repository metadata.

Production: https://compi-marketing.pages.dev

This is a direct-upload Pages project. Pushing to GitHub does not automatically deploy it; run the deployment command after approving a change. Custom-domain attachment is separate.

## Documentation sources

`/docs.html` is a separate, searchable guide with desktop navigation and mobile Contents. Its HTML is generated by `tools/generate-docs.mjs` from the checked-in `content/0.5.0/` snapshots. The CLI reference comes from the release's actual `help.rs` catalogue, with provenance in `cli.json`.

To refresh the pinned sources from a local Compi checkout:

```sh
node tools/import-docs.mjs PATH_TO_COMPI_REPOSITORY v0.5.0
npm run build
npm run check
```

For a new release, update the version in the generator as well as importing that tag. Keep documentation claims tied to the published release, not development `main`. Do not edit generated `docs.html` directly. Shared `theme.js` keeps the saved appearance consistent between the landing page and documentation.

## Content and appearance

- Downloads and platform caveats are pinned to the published Compi 0.5.0 release.
- Neutral is the default appearance. Warm Carbon uses the original semantic colors from Compi's `crates/compi-client/themes/warm-carbon.json`.
- Product screenshots and the recorded demo are real supplied media. They are not recolored by the page appearance toggle.
- Desktop uses sticky reading previews; mobile, short viewports and no-JavaScript browsers receive stacked views. Scrolling remains native.
